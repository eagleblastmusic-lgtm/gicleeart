Brak danych analitycznych

Aby rozpocząć zbieranie ruchu, dodaj Custom Pixel w Shopify Customer Events.

  1. Ustaw ANALYTICS_COLLECT_SECRET w pliku .env
  2. Uruchom serwer analityki z GicleeApp
  3. Wklej kod pixela w Shopify Admin → Pixeli klienta
  4. Kliknij „Wyślij event testowy”

          Pomiń mój ruch

          Wyklucz testy z KPI. IP = publiczny adres (ten sam co przy testach sklepu z domu), nie 192.168…. Visitor ID = pewniejsze (z pixela).

          Ostatni visitorzy w bazie

          Stare eventy nie mają zapisanego IP — wybierz swój Visitor z listy (najczęściej ten z największą liczbą eventów, jeśli to Ty testowałeś sklep).

          Generator linków UTM

          1) Wybierz szablon lub wpisz parametry · 2) Uzupełnij ścieżkę produktu (np. /products/obraz-canaletto) · 3) Kopiuj link · 4) Wklej w Instagram/bio/mail — wtedy w Źródła zobaczysz kampanię zamiast „direct”.
