## Operating rules

- `eagleblastmusic-lgtm/gicleeart` / `master` is the canonical monorepo history.
- `eagleblastmusic-lgtm/gicleeapp` / `main` is the controlled `cursor-api/` snapshot and implementation environment.
- Shopify theme work starts on current branches in `gicleeart-gpt`, then is imported as an exact verified patch into `gicleeart`.
- Never write directly to `main` or `master`.
- Every implementation package gets a branch, draft PR, tests, changed-file list and rollback instructions.
- No merge, Shopify deploy, history rewrite or destructive data cleanup without separate approval.
- Import one verified package into the monorepo at a time.
- Runtime data is copied and hash-verified before it is removed from Git tracking.
- The GPT knowledge ZIP is not generated by this programme.
