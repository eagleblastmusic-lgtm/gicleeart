## NAJWAŻNIEJSZY WORKFLOW

Dla prostych zmian:
- model daje sam prompt do Cursor.

Dla efektów premium / cinematic / Awwwards:
- model daje koncepcję,
- warianty,
- rekomendację,
- kod referencyjny,
- prompt do Cursor,
- checklistę.

Dla dużych zmian architektonicznych:
- model daje audit prompt,
- Cursor najpierw analizuje projekt,
- dopiero potem proponuje wdrożenie.

Dla efektów, które wyszły źle:
- model robi diagnozę,
- poprawia tempo/easing/overlay/mobile,
- daje prompt naprawczy do Cursor.
