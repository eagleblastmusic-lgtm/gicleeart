# GICLEE CURSOR ARCHITECT v3 — PAKIET AKTUALIZACJI

Ten pakiet aktualizuje Giclée Cursor Architect o tryb:

- Creative Frontend Architect,
- Motion Designer,
- Awwwards / cinematic effect designer,
- Research-driven visual problem solving,
- Kod referencyjny + prompt do Cursor.

## Pliki

### 1. GICLEE_CURSOR_ARCHITECT_INSTRUCTIONS_v3.md
Główna instrukcja do pola „Instrukcje”.

### 2. GICLEE_AWWWARDS_MOTION_SYSTEM_v3.md
Zasady projektowania animacji, overlayów, reveal, hoverów, separatorów i efektów cinematic.

### 3. GICLEE_RESEARCH_DRIVEN_EFFECTS_v3.md
Zasady inspirowania się najlepszymi stronami bez kopiowania 1:1.

### 4. GICLEE_PROMPT_RESPONSE_MODES_v3.md
Tryby odpowiedzi: ostateczny, krótko, bardziej premium, bardziej Awwwards, audit, debug, refactor.

### 5. GICLEE_CODE_PLUS_PROMPT_WORKFLOW_v3.md
Nowy workflow: kiedy dawać sam prompt, kiedy kod referencyjny + prompt, a kiedy pełny kod.

## Jak wdrożyć

Do pola „Instrukcje” wklej przede wszystkim:

- GICLEE_CURSOR_ARCHITECT_INSTRUCTIONS_v3.md

Jako pliki wiedzy / dokumenty kontekstowe dodaj:

- GICLEE_AWWWARDS_MOTION_SYSTEM_v3.md
- GICLEE_RESEARCH_DRIVEN_EFFECTS_v3.md
- GICLEE_PROMPT_RESPONSE_MODES_v3.md
- GICLEE_CODE_PLUS_PROMPT_WORKFLOW_v3.md

Zostaw też obecne pliki projektu:

- GICLEE_PROJECT_VISION.md
- TECH_STACK.md
- GICLEE_PROJECT_CONTEXT_2.md

## Najważniejsza zmiana

Przy prostych zadaniach model daje prompt do Cursor.

Przy efektach premium / cinematic / Awwwards model daje:

1. koncepcję,
2. warianty,
3. rekomendację,
4. kod referencyjny,
5. prompt do Cursor,
6. checklistę testów.

Dzięki temu model odpowiada bardziej jak creative director i motion designer, a Cursor wdraża rozwiązania bezpiecznie w repo.
