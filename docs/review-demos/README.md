# Nagrania podglądu dla Custom GPT

Pliki generowane przez **GicleeApp → Integracja z GPT → Nagraj podgląd** (Playwright).

| Plik | Opis |
|------|------|
| `latest-desktop.webm` | Scroll strony głównej, viewport 1280×720 |
| `latest-mobile.webm` | Scroll strony głównej, viewport 390×844 |

Nagrywane z **theme dev** (`127.0.0.1:9292`) gdy działa — wtedy widać zmiany z dysku bez deployu.

Te pliki trafiają do repo lustra GPT przy **Push → GPT GitHub** (jeśli są na dysku).
